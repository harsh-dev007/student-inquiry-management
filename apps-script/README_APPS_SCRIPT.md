# Apps Script files (paste into Google)

Use these five files in the Apps Script project attached to your Student Inquiry Management spreadsheet.

1. `Code.gs`
2. `Config.gs`
3. `Database.gs`
4. `GoogleForm.gs`
5. `Auth.gs`

Run `setupDatabase` once, then **Deploy → Web app → Who has access: Anyone**.

After any code change, deploy a **new version**. Saving the script is not enough for the `/exec` URL.
